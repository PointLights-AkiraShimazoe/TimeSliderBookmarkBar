# Time Slider Bookmark Bar

Maya 標準の Time Slider Bookmark を、タイムスライダー上に **色帯＋名前＋レンジで常時表示**し、
追加・リネーム・色変更・移動・範囲変更・削除・再配色・タイムレンジ操作までを、
ドッキング可能なコンパクト UI から行える Maya 用ツールです。

---

## 主な機能

- タイムスライダー上に **色帯を常時表示**（名前＋レンジ併記。範囲が重なるブックマークは段に積んで表示）。
- **ドッキング可能なコントロール UI**（Maya の `workspaceControl`）。バー表示 On/Off、レンジ表示 On/Off、
  バーサイズ（上下2つのつまみ＝帯の上端／下端）・フォントサイズ・アルファの縦スライダー。
- ブックマークの **追加**（Name / Start / End / 色）、**リネーム＋色変更**、**ドラッグで移動**、**端ドラッグで範囲変更**。
- **削除モード**（帯をクリックで削除）、**全色ランダム再配色**（隣り合うブックマークは別色になる）。
- 帯を **Ctrl / Shift + クリック**で、隣接・全体のレンジからタイムレンジ（St/Ed）を設定。
- 設定は **Maya 再起動後も保持**（`optionVar`）。
- **ドックのレイアウトも記憶**：ドック位置・タブの結合・最後に開いていたタブ（バーコントロール／カラー）を
  Maya のワークスペースが覚えて、次回起動時に自動復元。
- Maya 2020 以降 / PySide2 / PySide6 対応。

---

## インストール（ドラッグ＆ドロップ・推奨）

1. 最新リリースの ZIP をダウンロードし、**どこでも良いので解凍**します（一時フォルダや Downloads で構いません）。
2. Maya のビューポートに **`install.py` をドラッグ＆ドロップ**します。
3. **［Install］** を押すと、シェルフに `BMBar` ボタンが追加されます。
4. シェルフボタンから起動します。

> インストーラはツールを Maya のユーザーフォルダ（`…/maya/modules/TimeSliderBookmarkBar/`）へ
> **コピー**して自己完結させます。したがって **インストール後は、解凍したフォルダも ZIP も削除して構いません。**

### インストーラが行うこと
- `scripts/` と `icons/` を `…/maya/modules/TimeSliderBookmarkBar/` へ **コピー**します。
- Maya モジュール `…/maya/modules/TimeSliderBookmarkBar.mod` を作成し、そのコピー先を参照します
  （解凍場所に依存せず、毎回の起動で有効）。
- `tsbl.show_controls()` を実行する **シェルフボタン** を追加します。

### 更新方法
新しいリリースの ZIP を解凍し、同じように `install.py` をドラッグ＆ドロップして［Install］するだけです
（コピー先を上書き更新します）。更新後は Maya を再起動してください。

## インストール（手動）

`scripts/timeslider_bookmark_labels.py` を Maya のスクリプトパス上の任意のフォルダ
（例：`…/Documents/maya/scripts`）にコピーし、スクリプトエディタ（Python）で次を実行します。

```python
import timeslider_bookmark_labels as tsbl
tsbl.show_controls()
```

## 使い方

シェルフボタン、または `import timeslider_bookmark_labels as tsbl; tsbl.show_controls()` で起動します。

UI は Maya のドックタブ2枚（**バーコントロール** と **カラー**）で構成されます。

バーコントロールタブ（左→右）：バー On/Off、バーサイズの上下2つまみスライダー（上＝帯の上端／下＝帯の下端）、
フォントサイズスライダー、アルファスライダー、レンジ On/Off、右側に **＋**（追加）とその下に **−**（削除モード）。

### 帯（タイムスライダー上）の操作
- **短いシングルクリック** … リネーム＋色変更（帯の直上にポップアップ）。
- **中央をドラッグ** … ブックマークを移動（長さは保持）。
- **ダブルクリック** … その帯の範囲をタイムスライダーの St/Ed に設定。
- **左右の端をドラッグ** … 開始／終了フレームを変更（掴んだ端がハイライト）。
- **Ctrl + ホバー→クリック** `◀ ● ▶` … 一つ前 / 全ブックマーク全体 / 一つ後 の範囲を St/Ed に設定。
- **Shift + ホバー→クリック** `◁ ▷` … St だけを前のブックマークの Start に / Ed だけを次のブックマークの End に設定。
- **削除モード**（− ボタン ON、赤く発光）… 帯をクリックで削除。

### 追加 / カラー
- **＋** で、**色 / Name / Start / End** と ✕ / ◯ ボタンを持つコンパクトなポップアップを開きます。
- **カラータブ** の虹色ブックマークボタンで、**全ブックマークの色をランダムに再配色**します
  （時間的に隣り合うブックマークが同じ色にならないように調整）。

### 位置合わせ（`inset`）
帯はフレーム目盛に対して小さなピクセルインセット（既定 **12px**、Maya 2027 で調整）で整列します。
中央では合うのに端に行くほど左右対称にズレる場合は、次でライブ調整できます。

```python
tsbl.set_inset(12)      # 左右両方。端が揃うまで増減
```

値は保存され、次回起動時にも使われます。

### ドック位置 / アクティブタブ
一度好きな位置にドッキングすれば、Maya が位置・タブ結合・最後に開いていたタブ（バーコントロール／カラー）を
記憶し、次回起動時にそのレイアウトを自動復元します（毎回ドックし直す必要はありません）。
Maya のワークスペース復元が不安定なときは、記憶なしで起動するか、診断を実行してください。

```python
tsbl.show_controls(persist=False)   # フロート表示（レイアウト記憶なし）
tsbl.debug_persist()                # 永続化まわりの状態を出力（トラブル切り分け用）
```
